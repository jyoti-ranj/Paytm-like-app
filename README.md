# 💸 Paytm Clone - Money Transfer App

A simplified Paytm-like web application built using **MERN stack**, enabling users to securely sign up, sign in, search users, and transfer money. It features protected routes, JWT-based authentication, and a clear transaction feedback system using modals.

---

## 🚀 Features

- ✅ **User Authentication**  
  - Sign up, Sign in, and update profile  
  - JWT-based protected routes

- 🔎 **User Search**  
  - Search users by name or email to initiate a transfer

- 💵 **Money Transfer**  
  - Transfer money to other users  
  - Validations for sufficient balance and account ID

- ✅ **Transaction Feedback**  
  - Separate success & failure modals  
  - Retry option with pre-filled data on failed transfers

- 🎨 **Responsive UI**  
  - Tailwind CSS-based clean and mobile-friendly interface

---

## 🛠️ Tech Stack

### Frontend
- React
- React Router DOM
- Tailwind CSS
- Axios

### Backend
- Node.js
- Express.js
- MongoDB + Mongoose
- JWT (Authentication)
- Bcrypt (Password Hashing)
- Zod (Validation)

---

```bash
cd backend
```
